Multi-Level Parking lot Manager

Supervisor's Name: Dr. Madhavi Karumudi
Abstract: The Multi-Level Parking Lot Manager is a system designed to efficiently manage parking spaces in a multi-level parking facility. The system helps organize vehicles across different floors by keeping track of available and occupied parking spaces. It can assist in assigning suitable parking spaces to vehicles and updating the parking status when vehicles enter or leave. The main aim of the project is to reduce confusion and manual effort in parking management while making the process faster and more organized. The system provides a simple and efficient way to manage parking spaces and improve the overall parking experience.
